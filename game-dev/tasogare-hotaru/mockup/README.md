# デジタルモック：たそがれホタル

盤面・駒の動きを視覚的に確認するための簡易React実装です。ビルドツールは使わず、React / ReactDOM / Babel Standalone を
`vendor/` にローカル同梱し、ブラウザ上でJSXをそのまま実行しています（本サイト本体と同じく「サーバー1つで動く」構成に揃えています）。

## 起動方法

このリポジトリのREADMEと同様、ルート相対パスではなく相対パスのみで構成しているため `file://` でも動作しますが、
念のため簡易サーバー経由での確認を推奨します。

```bash
cd game-dev/tasogare-hotaru/mockup
python -m http.server 8080
# http://localhost:8080/ を開く
```

## できること（実装済みの最小操作）

1. **プレイヤー人数を選んでゲーム開始**（2〜4人）
2. **「ホタルを3つ引く」**：巾着袋からホタル駒3個をランダムに引く（袋引きの再現）
3. **引いたホタルを配置**：現在地のリリーパッドに置く、または手元にストックする（最大2個）
4. **ガーディアン駒を1〜3マス移動**：到着したマスのホタルを自動で星座に取り込む
5. **ターン終了**：たそがれトラックが1マス進む。トラックが最後まで進むと「たそがれラウンド」（画面が暗転し、女王ホタルが光る演出）に突入し、全員がもう1手番ずつ行った後に最終得点が表示される
