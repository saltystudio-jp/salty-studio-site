# 自己評価：たそがれホタル

`mockup/` の実装で確認できたルール骨子・体験の手触りをもとに、以下の5軸で自己採点した。

| 軸 | 評価（5段階） | 根拠 |
|---|:---:|---|
| 新規性 | ★★★★☆（4） | 「時間経過を物理的な木駒（たそがれトラック）で可視化し、強制的に終盤の演出ラウンドへ突入させる」構造は、Karuba/Tsuro的なタイル進行やCascadia的なパターン収集とは一線を画す。ただし「タイル進行＋袋引き収集」自体はジャンルとして新しくはないため、満点ではなく4とした。 |
| 面白さ（プレイの起伏） | ★★★☆☆（3） | モック上で基本ループ（引く→置く／ストック→進む→ターン終了）は破綻なく動作し、たそがれトラックが迫る緊張感の骨格は確認できた。一方で、風カードによる毎ラウンドの得点条件変化を今回のモックでは未実装のため、実際のリプレイ性・駆け引きの起伏は書面上の想定に留まり、実測できていない。 |
| 商品としての魅力（パッケージ・木駒の見栄え込み） | ★★★★☆（4） | 女王ホタル1個だけを蓄光塗装するという「一点豪華主義」は、コストを抑えつつ強いフックを作れており、既刊2作（貝殻・木の実モチーフ）と並べたときのシリーズ訴求力も高いと判断。ただし実物の質感・発光の見え方は試作未検証のため、確信度は最大評価ではなく4とした。 |
| 製造難度・コスト感 | ★★★★☆（4） | 全駒を半球・円錐・球体・円盤という基本形状に絞り、特殊加工（蓄光塗装）を女王ホタル1個に限定したことで、案A（動物シルエットのバランス駒）や旧案C（全駒蓄光）と比べて量産リスクを大きく抑えられている。ただし蓄光塗料の安全基準対応・発光品質は外部業者との試作検証が未実施のため、5にはしていない。 |
| ルールの理解しやすさ | ★★★★☆（4） | ターン構造（引く→置く→進む→終わる）はシンプルで、たそがれトラックという視覚的なタイマーがあることでゲーム全体の見通しが立てやすい。一方、手元ストックの上限・風カード条件・女王ホタルの加護など細部のルールは初見だとやや説明が必要で、5にはしていない。 |

## 次にやるべき改善アクション

1. **風カード24枚の具体案を設計し、モックまたは紙プロトタイプに実装して遊ぶ**：現状「面白さ（プレイの起伏）」の評価が書面上の想定に留まっているため、実際の得点条件バリエーションを組み込んだ状態でのプレイテストを行い、リプレイ性を検証する。
2. **女王ホタル駒の蓄光塗装について、木工・塗装協力先に試作見積もりを依頼する**：発光の輝度・持続時間・玩具安全基準（食品衛生法や国内outer玩具安全基準など）への適合を確認し、「商品としての魅力」と「製造難度・コスト感」の評価を実測値に基づいて更新する。
3. **紙・木材の簡易現物プロトタイプで実プレイ時間とバランスを検証する**：想定プレイ時間（25〜35分）と、袋引きの運要素・配置選択のバランスが実際に成立するかを、対象層（既刊購入者層を想定した8歳以上のファミリー〜ライトゲーマー）でのプレイテストを通じて確認し、`rules.md` の得点計算・ラウンド数を必要に応じて調整する。
